Install

GarageStack runs in Docker on any 64-bit machine: a PC, a NAS, a home server or a Raspberry Pi 4 or 5.

Before you start

  • A 64-bit host, linux/amd64 or linux/arm64. 32-bit ARM is not supported.
  • Docker 23.0 or later, or Podman with Docker Compose compatibility.
  • An MG iSmart account with your car already linked in the official app.
  • Outbound internet access, for the MG servers and the map services.

One session per MG account. Signing in anywhere else with the same account, the official MG app included, signs GarageStack out. GarageStack also needs the owner account, so give the MG app a secondary account instead:

  1. In the MG app, open Settings > Account management > Add secondary account.
  2. Invite a second email address and accept the invite on that account.
  3. Give the secondary account access to your car.
  4. Use the secondary account in the MG app, and the owner account in GarageStack.

Option A One container

A single image with everything inside: the web app, PostgreSQL, the MQTT broker and the SAIC gateway. The easiest way to start, and ideal for a NAS. 

docker run -d \
  --name garagestack \
  -p 8080:80 \
  -v ./garagestack-data:/data \
  -e SAIC_USER=your@email.com \
  -e SAIC_PASSWORD=yourpassword \
  -e SAIC_REGION=eu \
  -e CORS_ORIGIN=http://192.168.1.100:8080 \
  ghcr.io/joszz/garagestack:latest
  • SAIC_REGION is eu, au, tr or br. CORS_ORIGIN is the address you open in your browser.
  • Open port 8080 and sign in with your MG login, or set AUTH_USERNAME and AUTH_PASSWORD, or single sign-on.
  • The database password is made for you on the first start and kept in the data folder.
  • latest is the newest release. Pin a version such as 0.25.0 to choose when you update.

Option B Docker Compose

Separate containers for each part, so they update on their own and you can use your own PostgreSQL server. Needs Docker Compose 2.20 or later.

  1. Get the compose file

    git clone https://github.com/joszz/garagestack.git
cd garagestack
cp .env.example .env

  2. Fill in .env

    SAIC_USER, SAIC_PASSWORD
    Your MG iSmart login.
    SAIC_REGION
    eu (the default), au, tr or br.
    CORS_ORIGIN
    The address you open in your browser, such as http://192.168.1.100:8080.
    POSTGRES_PASSWORD, MQTT_BROKER_PASSWORD
    Make each with openssl rand -hex 32.

  3. Start it

    docker compose --profile bundled-postgres up -d

    With your own PostgreSQL server, set the POSTGRES_* settings in .env and run docker compose up -d. The app is on port 8080.
