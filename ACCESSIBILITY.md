# Accessibility Statement

## Commitment

GarageStack is an open-source community project that aims to be usable by as many people as possible. Accessibility is important, and improvements will be made where practical and within the project's available time and resources.

## Current Status

At this time, accessibility has not been a primary focus during development. As a result, GarageStack has not undergone a formal accessibility review and may not fully conform to accessibility standards such as WCAG 2.1 or WCAG 2.2.

Known limitations may include:

- Incomplete keyboard navigation support.
- Missing or insufficient labels for assistive technologies.
- Inconsistent color contrast in some areas.
- Limited testing with screen readers and other assistive technologies.

## Best-Effort Approach

Accessibility improvements are implemented on a best-effort basis by project contributors. When accessibility issues are identified, reasonable efforts will be made to address them, taking into account project priorities, available resources, and community contributions.

## Feedback and Reporting Issues

If you encounter an accessibility issue while using GarageStack, please open a GitHub Issue and include:

- A description of the problem.
- Steps to reproduce it.
- Information about any assistive technology being used.
- Screenshots or recordings if available.

Accessibility-related feedback and contributions are welcome.

## Ongoing Improvements

As the project evolves, accessibility considerations will increasingly be incorporated into new features and UI improvements. Community contributions that improve accessibility are especially appreciated.
